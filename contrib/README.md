# Contributed assets

One folder per asset: `contrib/<kind>/<asset-name>/` with the `.glb` file(s) and a `README.md`:

```
# Neon Mohawk
by: your name or handle (this is how you are credited)
kind: hair            (outfit, shorts, hair, headgear, face-shield, mask, gauntlet, prop)
fits: masculine and feminine heads (two files: neon_mohawk_m.glb, neon_mohawk_f.glb)
notes: the crest uses av_glow
```

See `CONTRIBUTING.md` and the template pack for how to make one. Contributions are published under CC BY 4.0.
