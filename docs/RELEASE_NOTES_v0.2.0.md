# Project Arena 0.2.0 (draft)

A standalone 1-v-1 VR ball sport for Meta Quest 3 (Quest 2 / Pro / 3S listed, not yet tested), inspired by Sparc.
Original art and sound; not affiliated with CCP Games.

## Install
Sideload with SideQuest or adb (developer mode on the headset):

    adb install -r ProjectArena-release-open.apk

It appears under Library → Unknown Sources as **Project Arena**.

## In this release
- Practice against a bot (Basic and Advanced rules): throws with spin and curve, shields, knuckle guards, strikes
  that grow and speed up the ball, returns, self-hits.
- Two-headset LAN play with a host / join menu, and spectating: a hub of live miniature arenas, or watch full size.
- Neon glass arena with baked lighting, plasma ball with live arcs, controller-in-gauntlet hands, 27 synthesized sounds.
- Avatars: waist-up humans with arms that follow your hands; 8 suits (incl. a Tron-style Grid Runner), builds,
  patterns, hair, headgear, face shields, masks and colours; a mirror builder; your look is shown to other players.
- In-VR name entry, saved settings, a first-run how-to-play panel.

## Known limits
- LAN only (online play through community servers is planned).
- Both headsets need the same version to see each other.
