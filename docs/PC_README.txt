Project Arena for PC VR (SteamVR, Meta Quest Link / Air Link, Windows Mixed Reality, Virtual Desktop)
==========================================================================================

Requirements
  - Windows 10 or 11, 64-bit, a graphics card with OpenGL 4.3 (any GeForce GTX 900 / Radeon RX 400 or newer)
  - A PC VR headset and an OpenXR runtime: SteamVR (Valve Index, Vive, most headsets) or Meta Quest Link
    The game uses whichever runtime is set as "active" (SteamVR: Settings > OpenXR > Set SteamVR as OpenXR runtime).

Install
  1. Unzip this folder anywhere (for example Documents\ProjectArena). Keep the "assets" folder beside the exe.
  2. Start SteamVR (or Quest Link) and put the headset on.
  3. Double-click ProjectArena.exe. A window on the desktop shows what the headset sees.

Play together
  - Same home network: MENU > MULTIPLAYER, then HOST GAME on one, PLAY on the other.
  - Over the internet: SETTINGS > SERVER, type the community server address (host:port), then ONLINE: ON.
    Quest and PC players meet in the same arenas.

Controls (Valve Index)
  Trigger  grab / throw          Grip  shield / push-to-talk (left)
  A        confirm / ready       Right B   recenter
  Left B   menu                  Sticks    turn / spectator flying

Your files (settings, avatar, name, cameras, log): %APPDATA%\ProjectArena
If the game does not start, open %APPDATA%\ProjectArena\projectarena_log.txt.
