# Project Arena 0.3.18

## New
- **UPDATE NOW updates the game right there (Meta store version)**: when a new version is out, UPDATE NOW asks the
  store for it and shows DOWNLOAD UPDATE with its size, then the download's progress, then INSTALL AND RESTART. The
  headset installs it and opens the new version; your settings stay. If the store can't update it, the page says
  why and offers the store page.
- **The store page for everyone**: copies installed from GitHub or SideQuest now offer OPEN THE STORE PAGE next to
  the GitHub page. To switch to the store version, uninstall this copy first (a store copy starts new career stats).

0.3.14 to 0.3.18 play together online.
