# Older versions

The [releases page](https://github.com/jendoebelin/ProjectArena-public/releases) shows only the current version, so
it's easy to find. The newest download is always at
**https://github.com/jendoebelin/ProjectArena-public/releases/latest**.

Older builds are not supported: the alpha needs every player on the latest version (online play, statistics and The
Crowd expect it), and the game says **UPDATE AVAILABLE** when a newer one is out. If you need an older build for a
reason (testing, a bug that only shows in an older version), ask at vrsportsfan@gmail.com or on the Discord server,
https://discord.gg/KuNkSbVHzh.

What changed in each version is kept in the release notes in this folder: `RELEASE_NOTES_v0.3.*.md`.
