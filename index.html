Project Arena / Asset viewer

VLoading the game's models

Every model, texture and sound in the game, drawn from the game's own files with a copy of its shader and rig. Each has an ID and a download: refer to anything by its ID ("V14 needs a longer hem", "S12 is too harsh"), or send a replacement file for that ID.

Make your own

  1. Find the part here and download it (below the view settings: each ID has its own).
  2. Make yours in Blender on the template pack : the game's bodies and heads, the glove, examples, and a README that says what goes where.
  3. Send it with the ID it replaces or adds to: a pull request or the Discord. Sounds: try yours in the game's SOUND STUDIO first.
